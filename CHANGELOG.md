# Changelog

Todos los cambios notables de este proyecto se documentan en este archivo.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/),
y el versionado sigue [Semantic Versioning](https://semver.org/lang/es/):

- **MAJOR** — cambios que rompen compatibilidad con lo que ya funcionaba
  (ej. cambiar el formato del `.env` de forma incompatible, quitar o
  renombrar un endpoint sin dejar el anterior funcionando, cambiar la
  estructura de `registry/applications/*.yaml` de forma que los YAML
  existentes dejen de ser válidos)
- **MINOR** — funcionalidad nueva que no rompe nada existente (nuevos
  templates, nuevas apps del catálogo, nuevos endpoints, nuevas
  integraciones)
- **PATCH** — arreglos de bugs, sin cambiar cómo se usa nada
